# 银杏家园与三位伙伴

## 桥头的一片叶

石桥边有一棵老银杏。起风时，叶子沙沙响，连溪水声都听不清。奶油追着一片打转的叶子绕回了原地。桃桃在暖廊的三扇窗上各摆了一朵叶花，团团发现窗花的影子刚好落在桥面上。奶油顺着三朵金色的影子找到了家。

暖廊成了大家约好见面的地方。Alice 搬来时，窗篮里留着一把金叶。《暖廊的彩窗》从这里开始。主线第一章从石桥边的约定开始。风吹散了窗花，大家还在等桥面上的三朵金花。Alice 与伙伴一起回来数叶、补齐三扇窗，朋友便沿着光影相聚。家中永久出现三扇叶花和地面的金影，十九片叶子的变式作为章后挑战。

《风过暖廊》让 Alice 亲历这次赴约。桃桃听见木窗漏风，用前爪压住围巾，俯身把篮里的五片金叶推过来。左、中、右三扇窗分别还亮着四格、三格和零格。若先把远窗填满，奶油会抬眼望过去，脚下仍停在断光处。等桥上的影子接起来，它才跑进暖廊与桃桃碰面。家里的伙伴仍由 Alice 选择，来演这场戏的是桃桃和奶油。

| 地方 | 在故事中的用途 |
|---|---|
| 庭院与石桥 | 三位伙伴约定的集合点。叶子、溪流、云影都能作为回家的路标。 |
| 暖廊 | Alice 的日常小家。窗座留给读书和等朋友的人，三扇窗是第一章数学的场景。 |
| 花园、树屋 | 花园收集植物与叶形，树屋可以往下观察叶脉和水流，往上看天气。 |
| 花店、甜品店 | 花店为朋友搭配花束与颜色，甜品店让大家把点心分给来访的伙伴。可进入空间、陈设和取名已实装。 |

## 奶油 · 银杏狐

奶油想画一张下雨也认得出的回家地图。它爱领路，也会被一片新叶子带错方向。桃桃提醒它回头数窗，团团从桥边帮它看影子的方向。遇到难题时，它会先试一条路，走错就把弯路也画进地图。

“跟上我！啊，等一下……这片叶子刚才来过。”

它听到呼唤会跑近，喜欢被摸尾巴。施展**银杏叶舞**时先压低身体，再扑进叶群，尾巴带出金色的弧线。栗色尾巴先冒芽、长叶，再张成金色扇尾，颈边生出一圈金叶，最后多层叶尾随跃身展开。

## 桃桃 · 月牙耳兔

桃桃想让暖廊的三扇窗各有一朵完整的叶花。它耳朵灵，喜欢听雨点的节奏，数急了也会把同一片叶子数两遍。它学会把数完的一组推到窗框另一边，也会请 Alice 来核对。

“你数这一扇，我数那一扇，最后一起对一对。”

桃桃受抚摸时轻轻一跳，放松时靠近蹭手。**月牙连跳**有一高一低两次腾跃。短垂耳渐渐变长，额头先出现月牙，两耳再竖成银月，耳缘长出云纹，最后像月光飘带。

## 团团 · 云翼猫

团团想看看云的另一面。小时候够不到窗台，它就在小水洼里看云。它习惯先停下来找影子，再把发现指给伙伴看。桃桃的窗花能把奶油带回家，就是它先在桥面上看见的。

“先别抬头。云的影子已经游到脚边啦。”

团团小时候靠爪子**踏云追风**。蓝白尾巴卷成云，肩上长出小云团。第四阶段第一次展翼，回到家中会收翼；第五阶段云翼展开，第六阶段翼尖和尾羽出现星点。幼年技能画面中的云气是风迹。

## 在游戏里读

首次选宠点「认识伙伴」可以读这位伙伴的介绍。已建家的孩子从「成长 → 银杏家园手记」打开开篇故事、三位伙伴的小传和当前阶段的外观笔记。角色小传连接到技能试玩。手记随安装包离线提供，翻阅、预演及互动均为只读操作。

家庭的正式成长来自家长确认的现实成果。想家时可以随时回来，伙伴会记得已经取得的外观。奶油把雨天走过的石板画成爪印，又用三个爪印为桃桃找了一条近路。画好的地图会留在伙伴回忆里。[开发计划](PLAN.md)
