# 家长最终验收单

Codex 交付可安装候选版本、iPad 与安卓的测试记录、两次迁移的前后摘要，以及问题清单。家长在独立测试家庭中体验。以下数字是家长真机验收期望。云端结果按版本保存在验收记录中。

## 0.15 的团团步态

安装安卓家庭更新后打开「小家」，让第一阶段团团分别走向点过的草地、响应「过来」、自己起身走动。原速看前后爪轮流承重，走到目标自然收步。给它穿上已有衣饰再走一次，看衣料和配饰怎样随着身体转动。转向有几帧前腿短暂交叉，可留意原速时是否自然。[家庭安装](DELIVERY.md) · [同机位录像与逐爪测量](evidence/cat-walk/README.md)

## 0.14 的《风过暖廊》

1. 从小家点「主线 · 风过暖廊」。看叶子从窗边落下，桃桃转耳、低头压围巾、用前爪把篮子往前推。右上角可静音，也可在「章节选项」收起对白。
2. 点篮子取一片，点中窗唯一的空格。看看木板和桥面接到哪扇窗的光，再看奶油向哪段桥走。每次再拿一片，把远窗余下四格补齐。
3. 看完团聚点「回暖廊看窗光」，再进入主线点「再演一次」。这次先补满远窗，看看奶油怎样回头望光、又在哪里等。中途退出再进，应从刚才补好的格子继续。
4. 在家庭已有第三阶段月牙耳兔时，可到衣橱给桃桃试戴围巾，分别搭配原装、外套或围裙。故事中的围巾是桃桃的戏服，家庭衣橱的所有权来自兑换。两次修窗后，到成长手记、积分账本核对原来的数值。

## 先看 0.13 的配饰与伙伴

从 **小家 → 衣橱 → 试穿衣服和配饰** 轮流试戴围巾、帽子、蝴蝶结和圆框眼镜，切换「原样」观察眼睛、耳根和颈部。用测试家庭兑换一件后回小家，点伙伴的技能，留意配饰在腾跃和落地时的位置。重开应继续戴着。帽子与蝴蝶结共用头饰位，围巾、眼镜与已购服装可以搭配。[四项试戴实拍](evidence/daily/phone-accessories.jpg) · [三宠动作对照](evidence/daily/three-skills.mp4)

打开 **成长 → 银杏家园手记** 读所选伙伴的小传。回小家从 **主线 · 暖廊的彩窗** 赴约，让 Alice 自己找出每扇窗的叶数和还缺的叶片。完章回暖廊看窗花，重玩后核对积分和经验。[主线背景与三宠设定](WORLD_AND_COMPANIONS.md)

- 安装方式和包版本明确；每份证据标注设备、系统、构建号和对应步骤。
