# 家长最终验收单

Codex 交付可安装候选版本、iPad 与安卓的测试记录、两次迁移的前后摘要，以及问题清单。双端验收使用安装说明列出的同一候选构建。家长在独立测试家庭中体验。以下数字是家长真机验收期望。云端结果按版本保存在验收记录中。[家庭安装](DELIVERY.md)

## 0.24 的食物兑换与喂食

1. 在「小家 → 成果兑换」查看食物货架。确认用 3 分兑换糖果、5 分兑换饼干或 8 分兑换布丁。回小家点「喂食」，核对各份数。
2. 选一份喂给当前伙伴。确认后对应食物少一份，亲密度增加 3、5 或 8，积分和经验与喂食前一致。切到另一只已解锁伙伴，核对它自己的亲密度。
3. 在「成果兑换 → 我的兑换」退回一份未喂的食物。核对库存和原付积分。覆盖更新、重启或恢复加密备份后，再核对剩余食物和已获得的亲密度。[备份与换机](BACKUP_MIGRATION.md#024-食物库存与喂食)

## 0.23 的进度条和成就

1. 在小家查看经验与亲密度两条进度条。用新测试家庭确认三件小事，核对经验到 3 后进化到 2 级，并看到「小小成长」徽章。若更正其中一件，经验进度应显示 2 / 10，进化徽章仍可在「成长 → 成就」看到。
2. 当天首次摸摸和呼唤分别跨到 1、2 点，核对「熟悉」和「默契」徽章。重复互动、回看进化和外观预览后核对徽章数量。切换已拥有的伙伴查看各自的成就。
3. 用旧档覆盖更新，核对已达标的徽章。冷启动或在兼容版本上恢复加密备份，再核对两条进度和徽章数量。

## 0.22 的亲密度与糖果

1. 在「小家」当天第一次摸摸伙伴、第一次点「过来」，分别核对亲密度增加 1。再做一遍两种互动，核对当天亲密度保持原数。打开「成长」查看距离下一阶段的数值。
2. 从「成长」或「成果兑换」打开「亲密度糖果」。确认用 3 分兑换一颗，查看颗数增加。确认喂给当前伙伴，核对糖果减一颗、亲密度加 3，积分余额和经验与喂食前一致。
3. 带另一只已解锁伙伴回小家，核对其亲密度。重启后，检查各自进度与剩余糖果。导出加密备份并恢复到兼容版本，在目标机再核对这两项。

## 0.17 的雨天地图和伙伴回忆

1. 在「小家」摸摸当前伙伴，再点「过来」。到「成长 → 伙伴回忆」查看两件回忆和默契。换一只伙伴，可以从它自己的亲密度继续。
2. 完成《风过暖廊》后，在「小家 → 主线」进入《奶油的雨天地图》。每段踩三块石板、盖一个爪印。可在第一段退出并重开，查看已走过的石板。盖齐四个爪印后，奶油把地图带回暖廊。
3. 点「帮桃桃铺近路」。试一遍少铺石板，看提示后按三个爪印铺九块。回小家后在伙伴回忆中可见完成的地图。对照试玩和重演前后的余额与经验，数值应一致。
4. 在家长「备份与迁移」发起导出，生成时点「取消」，核对家园仍可写、上次备份仍可回读。随后正式导出到系统文件位置，在装有同一候选版本的另一台设备恢复，核对两只伙伴不同的亲密度与雨天地图进度。

## 0.15 的团团步态

安装安卓家庭更新后打开「小家」，让第一阶段团团分别走向点过的草地、响应「过来」、自己起身走动。原速看前后爪轮流承重，走到目标自然收步。给它穿上已有衣饰再走一次，看衣料和配饰怎样随着身体转动。转向有几帧前腿短暂交叉，可留意原速时是否自然。[家庭安装](DELIVERY.md) · [同机位录像与逐爪测量](evidence/cat-walk/README.md)

## 0.14 的《风过暖廊》

1. 从小家点「主线 · 风过暖廊」。看叶子从窗边落下，桃桃转耳、低头压围巾、用前爪把篮子往前推。右上角可静音，也可在「章节选项」收起对白。
2. 点篮子取一片，点中窗唯一的空格。看看木板和桥面接到哪扇窗的光，再看奶油向哪段桥走。每次再拿一片，把远窗余下四格补齐。
3. 看完团聚点「回暖廊看窗光」，再进入主线点「再演一次」。这次先补满远窗，看看奶油怎样回头望光、又在哪里等。中途退出再进，应从刚才补好的格子继续。
4. 在家庭已有第三阶段月牙耳兔时，可到衣橱给桃桃试戴围巾，分别搭配原装、外套或围裙。故事中的围巾是桃桃的戏服，家庭衣橱的所有权来自兑换。两次修窗后，到成长手记、积分账本核对原来的数值。

## 解锁新的伙伴

打开「小家 → 伙伴」。新家只拥有自己选的首宠。在测试家庭累计 30 分，试着打开解锁确认后返回，余额应保持原数。再确认兑换，余额减少 30 分，新伙伴显示 1 级、0 经验。点「带回小家」，确认一件小事后切回首宠，分别核对各自的经验。关闭应用再打开，核对解锁、余额和当前伙伴。

## 先看 0.13 的配饰与伙伴

从 **小家 → 衣橱 → 试穿衣服和配饰** 轮流试戴围巾、帽子、蝴蝶结和圆框眼镜，切换「原样」观察眼睛、耳根和颈部。用测试家庭兑换一件后回小家，点伙伴的技能，留意配饰在腾跃和落地时的位置。重开应继续戴着。帽子与蝴蝶结共用头饰位，围巾、眼镜与已购服装可以搭配。[四项试戴实拍](evidence/daily/phone-accessories.jpg) · [三宠动作对照](evidence/daily/three-skills.mp4)

打开 **成长 → 银杏家园手记** 读所选伙伴的小传。回小家从 **主线 · 暖廊的彩窗** 赴约，让 Alice 自己找出每扇窗的叶数和还缺的叶片。完章回暖廊看窗花，重玩后核对积分和经验。[主线背景与三宠设定](WORLD_AND_COMPANIONS.md)
