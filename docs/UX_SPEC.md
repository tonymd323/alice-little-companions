# 页面与交互规格

开工基线 v1.1 · 2026-11-18。所有日常流程均为本地读写。儿童侧使用“小家、小事、成长、积分”等可读名称，不展示数据库、同步版本等工程术语。

## 关键流程

### 选择伙伴与回家

先看三位伙伴的初始外观和名字，再点「和它一起长大」选定唯一的免费首宠。「小家 → 伙伴」显示余额、解锁所需积分和每位已拥有伙伴的等级与经验。点「用 30 分解锁」后再次确认，新伙伴以 1 级、0 经验入住。点「带回小家」切换到这位已拥有的伙伴，显示它自己的外观、等级和搭配。切换免费。

成长页回顾已获得的外观。在“外观预览”中可比较三只宠物的六个阶段并返回当前，预览状态不写入正式存档。云翼猫第四阶段，日常小家显示收翼，跨过对应阈值时可以展示一次展翼；跳过庆祝即可返回已保存的家园。

### 创建与完成

家长自行输入名称（1—40字）、完成标准（1—300字），内容说明可选（最多500字）。选择任务类型后显示对应分值。单次可无截止日期；重复必须有明确日期规则和每日次数；项目各阶段分别填写标准与类型。

发布前展示将生成的实例与预算，防止误设重复次数。真实家庭不预填任务；开发夹具只能叫测试任务A/B/C。

儿童点击“我完成了”后显示待确认，不显示积分已到账。家长确认时显示原标准，不提供临时改分滑块。确认成功后先显示家长反馈，再显示积分与一次可跳过的庆祝；不循环播放、不自动推下一项。

退回使用“继续完成”，保留已有备注，不使用负面人物评价。没任务时显示宠物与“家长还没有添加任务”，不自动生成任务。

### 兑换与布置

目录预览必须显示当前积分、价格、兑换后余额；点击确认后等待本地事务结束。失败保留原状态。已拥有显示进入物品，不再次收费。

儿童误触撤销提供一次明确入口，按RULES时限执行；超出时限提供“请家长帮助处理”。不能用关闭弹窗等动作自动消费。

家具图册用同一个房间展示原样和摆好效果。窗台、窗座、门梁和地面各有固定画位，窄屏可在图册看局部。确认兑换后直接显示家具，主题空间打开时已有全套陈设。衣橱可以在伙伴身上试穿，确认兑换后立即穿上；更换、卸下与分别保存三位伙伴的搭配均免费。

退款整个空间时，其中单独购买的家具会回到暖廊。未解锁空间可看静态预览与价格，不出现倒计时、红点或追逐任务提示。

### 本地备份

家长进入数据页→导出备份→显示记录数量与余额→输入并确认备份口令→生成文件→系统文件保存面板→报告保存结果。提示“请保存到App之外的位置”；不能以私有缓存文件已生成当成外部备份成功。

如果平台保存接口无法确认最终位置，应显示“文件已交给系统，请确认已保存”，外部备份状态为未核实；通过重新选择该文件并验证后才标记已验证。

生成、回读、解密和创建恢复点期间显示正在进行的步骤。成果提交前可取消并重试，家长原存档、先前备份和可写状态保留。系统文件保存面板沿用平台取消入口。内部恢复点不能显示为已导出外部备份。

### 恢复与跨设备迁移

恢复可从首次使用或家长数据页进入。验证成功后显示备份时间、孩子称呼、余额、任务记录数、拥有物品数、成长阶段，并与当前数据并列。非空设备明确说明会整体替换，不能用“同步”字样。

先成功建立恢复前副本，再进入覆盖确认。密码错误或校验失败不能展示备份内部私人内容，不能改变当前家庭。

迁移导出显示“导出成功后这台设备将暂时只读，请在新设备恢复后继续使用”。传文件可用系统文件共享、电脑或用户自行选择的渠道，不要求登录App云账号。源设备保持已有数据，目标确认后由家长决定归档；不自动删库。

目标设备在激活恢复数据前重新设家长PIN和恢复密钥；恢复成功后核对余额、物品、场景、当前伙伴、各自搭配与成长。再次导入同一备份返回已恢复或要求明确覆盖，不累计余额。取消迁移只在家长明确确认目标没有继续使用时允许。

## 状态与反馈

| 状态 | 呈现 |
|---|---|
| 首次空数据 | 清晰的创建/恢复入口，无假数据 |
| 完全离线 | 核心功能照常工作；无需持续显示“离线错误” |
| 本地保存中 | 控件短暂忙碌，防重复点击；超时保留原状态 |
| 待家长确认 | 保留任务，不提前发分 |
| 余额不足 | 显示准确差额，不推荐刷任务或充值 |
| 数据校验失败 | 说明未替换当前数据，提供换文件/重试 |
| 未来备份版本 | 说明需要兼容版本，不能忽略未知字段强行导入 |
| 迁移只读 | 不允许新增任务、确认、消费或布置；允许查看和重复导出同一快照 |
| 恢复中断后重启 | 自动选最后一次完整有效的数据代，不露出半恢复状态 |
| 家长权限过期 | 重新解锁，保留未提交表单，不执行原操作 |

## 设备适配

iPad横屏以空间为主，右侧或底部少量入口；竖屏改上下布局。手机使用纵向页面，布置可进入专用全屏。按可用宽度布局，不锁定特定iPad型号，不将横屏缩小塞进手机。

儿童可点击区域至少48逻辑像素；文字默认至少16，主要操作18；家长正文至少14。支持系统字体放大至130%、减少动态效果、静音。文字不直接烘焙进图片；颜色不是状态唯一线索。
