# 第一阶段团团独立试玩

本次使用独立 Flutter 测试副本与合成家庭。正常入口在 390 × 844 视口从「暖廊」点「庭院」。候选源码与素材按目录逐文件比对，哈希见同目录 [源码摘要](independent-source-sha256.txt)。固定镜头画面从 Flutter 无损回放取样，原装前后片 25 fps，共 320 帧。播放器以原速无声播放，再回看具体帧。

原装正常入口测得逻辑坐标 x 依次为 186.26、41.86、240.41、132.11。动作前后及关闭重开数据库均核对阶段、余额、经验、修订号、账本、物品与穿戴。第一次纵向复测发现可见草地 (.398,.75) 落在伙伴方形触区内，目标 x=142.94，操作 5 秒后仍在 x=186.26。修复后从同一入口点击同坐标，实际到达 x=142.94。两项独立测试均通过，见[独立测试日志](independent.log)。纵向行走期间可见背向头部和四肢。 [纵向无损帧](depth-walk.png)

正视换侧脸有短暂轮廓变化，应用 f42–44 前腿短时交叉，可继续细化掉头的支撑过渡。实机帧率、家庭设备同签覆盖与跨端迁移尚需对应设备验证。
