# 0.21 首次建家回归

用私有 GitHub 的 **0.21.0+19** 原签名 APK，在 Android 9 x86_64 软件模拟器中开启飞行模式。从空应用数据分别建立三个测试家庭，依次选奶油、桃桃和团团。家长设置本机 PIN，按入口提示确认恢复密钥，再进入小家。用测试输入法填写合成数据。[APK 摘要](../package.json)

三次实际进入小家均只拥有所选首宠。首宠 1 级、0 经验，初始余额、预置小事和积分流水都是 0。每次强制退出并重开后，界面仍显示所选伙伴，30 张业务表摘要及活动存储代均与首次进入一致。团团小家的另外两只伙伴显示解锁还差 30 分，切换入口不可用。[奶油](fox.png) · [桃桃](rabbit.png) · [团团](cat.png) · [伙伴页](locked.png) · [复核数据](verification.json)

双端真机首次建家留在 AC-01。[逐项验收](../../acceptance.csv)

## 当天的小事与加密备份

在团团的新家中，家长填写两件小事的名称、说明和标准，都选「持续投入」。孩子从小事页分别申报，账本和经验仍为 0。家长确认后，余额 6 分，团团有 2 经验。[确认成果](parent-approved.png)

在成果兑换用 6 分兑换小花瓶，暖廊固定画位出现花瓶。冷启动后花瓶仍在，余额 0 分，团团有 2 经验。对比同机位下不含界面按钮的暖廊画面，变动集中在花瓶位置。[兑换前](cat.png) · [重启后](furnished.png)

从家长入口把普通加密备份保存到 Android 系统 Downloads，再选中原文件回读。App 显示外部文件已验证，源档仍可记账。另用 Node 解密并用 SQLite 校验 30 张业务表，确认与导出前一致，积分流水为 `+3`、`+3`、`−6`。[系统保存](backup-system-save.png) · [回读结果](backup-verified.png) · [过程与复核数据](offline-cycle.json)

清空模拟器中的测试应用数据，保留 Downloads 内的文件。在首次启动页选择「从备份恢复」，核对预览并设新家长 PIN。激活后冷启动，新的存储代与原档逐表比对一致，团团仍有 2 经验，小花瓶仍在暖廊，账本保留三条流水。用新 PIN 重新解锁家长入口成功。[恢复预览](backup-restore-compare.png) · [恢复后的小家](restored-cold.png)
