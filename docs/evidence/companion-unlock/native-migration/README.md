# 0.21 系统文件换机回归

使用原私有 GitHub 分支发布的安卓家庭包 **0.21.0+19**，构建提交为 `f3a7184aaeff2589f3ffe6ef6618ac21c0618288`。在一台 Android 9 云端软件模拟器的两个隔离用户中操作，两边各有独立应用存档和家长凭据，全程飞行模式。使用合成档和测试输入法，从应用正常入口完成操作。[安装包校验](../package.json) · [备份换机](../../../BACKUP_MIGRATION.md)

首台通过系统文件选择器恢复结构 8 的合成家庭。余额 5 分，奶油 3 级、16 经验，团团 1 级、0 经验。存档含一件待确认小事、窗花、雨天地图、家具、围巾、心愿和亲密回忆。

从家长入口进入「备份与迁移 → 迁移到新设备」，在系统文件面板把加密文件保存到 Downloads，再回到「回读验证导出文件」选择同一份文件。App 校验通过后首台处于只读。首台回读前后的 30 张业务表逐表比对一致。独立检查确认加密包可解密，包内业务摘要与初始合成档相同。[系统保存](a-to-b-system-save.png) · [回读结果](a-to-b-readback.png) · [摘要](verification.json)

将已验证的加密文件复制到第二个测试用户的 Downloads，从首次启动的「从备份恢复」打开。设置新家长 PIN 并激活后，第二端生成独立设备身份，30 张业务表与首台一致。两只伙伴的独立经验和已经解锁的状态随档恢复。[第二端恢复预览](target-compare.png) · [摘要](verification.json)

确认第二端恢复后，通过「归档旧设备」归档首台。首台冷启动仍为只读，存储代和业务摘要与迁出前一致。[首台归档](source-archived.png)

在第二端切换到团团并确认待办小事。余额从 5 分升至 7 分，团团新增 1 经验，奶油为 16 经验。继续踩过雨天地图的第二块石板，重开后进度保留，积分和各自经验与进入剧情前相同。[雨天地图进度](target-rain-resumed.png) · [摘要](verification.json)
