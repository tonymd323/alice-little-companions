# 《奶油的雨天地图》独立试玩

源码 `8010127d9743c25b42dfdef2984d359333492d11`，0.17.0+15。使用 390 × 844 的 Flutter widget 竖屏，从正式 `CompanionsApp` 和 `FamilyHome` 进入。测试家庭选桃桃，预先由家长确认一条测试成果，余额 3 分、经验 1。游戏使用真实文件型 SQLite 和正式 `FamilyService`。安全存储使用测试适配器。试玩前已知道制作人要求的四枚爪印与九块近路。

| 实际操作 | 看到的结果 |
|---|---|
| 从小家完成《风过暖廊》的五次取叶嵌窗，再返回小家、点「主线」 | 无需滚动就能在手机首屏点「主线」，下方列出《风过暖廊》和《奶油的雨天地图》。选择第二行后看到奶油解释雨冲走脚印，点「和奶油出发」。 |
| 第一段先盖印、直接点第三块，再依次踩第一和第二块 | 分别提示「还差3块石板」和「由近到远，先踩第一块石板」。已走的石板带勾，下一块有浅色描边。点返回离章再进入，前两块仍在；卸载 widget、关闭 SQLite 连接，并由新的家庭控制器重开原存档，再进入仍从第三块接续。 |
| 四段每段踩三块并手动盖爪印 | 地图逐段留下四印。暖廊里出现奶油与桃桃，桃桃的话将四个爪印和十二块石板联系起来。 |
| 近路铺八块或十块后点「带桃桃过桥」，再把十块减回九块 | 前者提示补满，后者提示收回；九块对应纸上三组三格，确认后出现桃桃学会近路的结局。 |
| 再次关闭并重开同一家庭，从「成长」进入「伙伴回忆」 | 可见原暖廊记忆、新章标题和四印地图。再回主线仍是已解开近路的结局。确认的是同一只桃桃、3 分、1 经验、1 条原有流水。 |

**观感**　出发按钮、石板上的数字和下一步提示够用，点错后能自己修正。近路的三个爪印下面各有三个槽，画面能解释为什么九块正好。途中画的是晴亮树屋与草地，编号石板更像浮在景上的按钮。为什么雨会冲掉路标主要由对白交代。真实二年级孩子能否独立发现通关后由「主线 · 风过暖廊」改名的「主线」，以及是否把石板读成渡河的路，留给家庭现场确认。

这些截图来自正式页面的 Flutter 测试渲染，使用本机中文字体。此次独立试玩没有操作实体 Android、iPad 或模拟器，也没有测量触摸延迟、步态流畅度或真机迁移。重开操作重建了组件、控制器和数据库连接。

续玩图是完整页面。《四印结局局部》《九块近路局部》裁自原画面。Flutter 测试字体将个别深色按钮的中文字绘成方块，动作名称由实际按钮文本和命中验证。签名包的字形以安卓安装画面为准。

独立测试日志中 7 项通过，包括这条正式首页独立试玩、两项地图 widget、旧版数据库升级、加密导出恢复、成长回忆和家庭主线续读。加密导出在调试构建中打印了 Drift 多数据库实例提示，往返恢复断言通过。这里未做实际换机。
