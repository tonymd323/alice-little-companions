# 0.21.3 安卓离线首次建家

在 Android 9 x86_64 模拟器开启飞行模式，关闭 Wi-Fi 和移动数据，从空应用数据安装 GitHub 的 `0.21.3+22`。校验系统中安装的 APK 摘要与发布记录一致，构建源码为 `27c38ac41461720defcca73d848ca81cf1f18b32`。[安装核对](environment.json) · [发布回执](../backup-ui-0213/github-download.json)

选云翼猫团团为首宠，设置家长 PIN。勾选恢复密钥保存确认后，进入小家的按钮才启用。团团以 1 级、0 经验入住，余额、预置小事和积分流水均为 0。伙伴页中另外两位各显示「解锁还差 30 分」。离开伙伴页后，业务摘要与首次进入一致。[首次进入小家](first-home.png) · [锁定伙伴](locked-companions.png)

从「家长入口 → 用恢复密钥重设」完成重设。新密钥确认页的提交按钮在勾选保存后启用。用第一次重设生成的密钥再次重设，核对新密钥实际可用。旧 PIN 得到「凭据不正确」反馈，新 PIN 在冷启动后解锁家长入口。活动存档与 30 张业务表摘要一致。[旧 PIN 反馈](old-pin-rejected.png) · [重设结果](recovery-verification.json)

家长填写名称、说明和完成标准，发布一件 2 分小事。孩子申报后待确认一件，积分流水和经验仍为 0。家长确认后，余额为 2 分，团团为 1 级、1 经验，账本新增一笔流水。[入账回执](approval-receipt.png)

从小家预览尚未解锁的奶油第六阶段。退出预览并冷启动，余额仍为 2 分，团团仍为唯一拥有的伙伴，持有 1 经验。预览前后及冷启动后的存储代、进度和 30 张业务表摘要一致。[第六阶段预览](locked-fox-preview.png) · [冷启动家园](cold-after-preview.png) · [逐步核对](verification.json)
