# 团团短程表演复看

[同机位对比](tuantuan-comparison.mp4) · [小样单看](tuantuan-rehearsal.mp4)

左边保留 0.16 的实际绘制。短程点地后，身体还停在原位置，第一帧就从圆臀坐姿换成较长的四足体态，坐下又切回原图。两个方向的旧长程录像也能看到脚点没动时，头和躯干在相邻两帧从侧面切到正面。玩家在原速里会先看到轮廓的突变。[0.16 运行绘制](../../../apps/mobile/lib/illustration/companion_walk_art.dart) · [原奶油录像](../fox-walk/three-walks.mp4)

右边用第一阶段团团的 C 版原画试一段好奇地走近。瞄向落点，尾尖随之动一下，前掌压实后撑起，走两小步，再收掌坐好、眨眼。首尾角色与原图逐像素一致。中间调整肩、臀、爪和尾的轮廓，沿用同一幅脸和耳的原画。[可编辑动作时序与原画工具](../../../design/production/cat-approach/README.md)

两侧均取 480 × 374 逻辑像素的小家庭院画面，原始帧 960 × 748。对比片 104 帧，以 25 帧每秒播放。两侧从同一草地点出发，目标在右侧 32.928 逻辑像素，脚线 y = 286.4。左侧由既有小家接收点地，右侧将透明角色帧合成在同一套 Flutter 背景上。复看的范围是原装第一阶段团团、同向两小步。覆盖游戏入口、转向、长路线和衣饰的发布验证留在完整动作接入后。

独立试玩发现第一轮有前后爪一起抬的画面。返修后，透明序列第 36–42 和 54–60 帧都能分辨前掌先抬、近后掌稍后跟上。行进中身体仍偏低，下一轮要继续画清肩背撑起与臀部移重。

复录可用 `apps/mobile/tool/capture_tuantuan_rehearsal_test.dart`。在预演工作树的 `apps/mobile` 内分别用 `COURTYARD_REHEARSAL=输出目录` 录 0.16 和空庭院，两份目录需要不同。空庭院额外设置 `COURTYARD_EMPTY_REHEARSAL=true`。原画导出透明序列后，在项目根运行 `python3 tools/compose_tuantuan_rehearsal.py 旧画面目录 空庭院目录 透明帧目录 设计清单 输出目录`。
