# 银杏家园家庭版开发计划

## 当前开发顺序

目标是让 Alice 在同一个离线家庭 App 完成日常小事、成长、兑换和二年级数学主线，并把整家带到另一台设备。0.17.0+15 先交付雨天地图、伙伴回忆和可取消的加密备份流程，回归已有账本、纠错、外观和兑换。双端安装、真实设备性能与往返迁移按设备接入情况留证。[验收表](evidence/acceptance.csv) · [安装与设备条件](DELIVERY.md)

家长试玩 0.16 后指出日常移动像机械狗。团团短程原画样片与桃桃草稿已保留，日常起身、迈步、换向和坐回列入后续美术返工。每次正式接入前从同机位看一轮原速。[团团同机位样片](https://github.com/tonymd323/alice-little-companions/blob/codex/tuantuan-motion-preview/docs/evidence/tuantuan-approach/README.md) · [桃桃基线](evidence/rabbit-hop/README.md) · [画面验收](ACCEPTANCE.md#小家画面与剧情验收)

| 顺序 | 谁做、交付什么 | 本阶段的完成条件 |
|---|---|---|
| 1 · 幼猫原画 | 原画与动画先交原装团团的起身、四拍八张慢走关键姿、转向和收步，同画布标四个爪垫和承重段。用庭院原机位做原速样片。客户端可同步接入步距计算与录屏工具。 | 独立试玩者在无特效小样中能指认哪只爪抬起、哪只在承重，看清重心如何移过去。缺姿势就列出并补画，0.14.1 继续可下载。 |
| 2 · 可安装的幼猫更新 | 工程把步态接入小家三种走动。美术补足一阶段外套、围裙及现有四种配饰在新姿态里的遮挡。独立试玩从同一家庭版正常入口操作。 | 三种走动均通过原速与锁足检查，旧家庭带来的衣饰在走动中可见。木梯回归、减少动态效果、重启、旧档和预览零入账通过。交同签 Android 更新包、源码、前后录像和已覆盖范围。 |
| 3 · 把日常陪伴做完整 | 以同一方法分批制作奶油、桃桃及后续成长形态。按物种设计行走或跳跃、抚摸、呼唤、技能起落与进化。同步复看庭院、暖廊、家具、窗花和衣饰，用原机位补透视、遮挡与投影。 | 一批对应明确的伙伴、阶段、动作、穿戴及房间。每批有可运行版本、同机位原速片和缺项清单。结论只覆盖实测组合。 |
| 双端交付 | 云端持续做离线、旧档、同签升级及备份回归。接入匹配的 Mac/Xcode、可用 Apple Team、iPad 和安卓真机后，工程执行安装、覆盖、性能及往返迁移。 | 同一候选版本在两个方向迁移后比对余额、经验、物品、穿戴、房间、任务、伙伴回忆与书签，另存各机型的安装与性能记录。 |

每批沿用原私有仓库的 APK 下载入口，保留 Git 提交、SHA-256、备份换机说明与对应证据。发行记录逐项写明功能结果、独立试玩结论、真机状态和家长验收状态。

### 团团 0.15.0+13 检查点

阶段 1 的原装原画已通过无特效独立试玩。阶段 2 在原家庭版接入点地、「过来」及自主走动。独立复看后修复了转面重影和透明边缘拦住点地的问题。固定镜头、衣橱两套组合、减少动态效果和假家庭重启均已复核。源码为 `9f9b51b`。[候选证据](evidence/cat-walk/README.md)

阶段 2 的安卓家庭包由发布 0.14.1 的原签名机重建。Android 9 模拟器在飞行模式覆盖更新和冷启动后，测试家庭的 26 张业务表摘要相同。转向时第 42–44 帧仍可见短暂前腿交叉。实体设备覆盖和双向迁移待验。[家庭 APK](https://github.com/tonymd323/alice-little-companions/blob/android-downloads/downloads/alice-0.15.0-android.apk?raw=true) · [签名机交接](DELIVERY.md#新会话接续安卓签名)

### 奶油 0.16.0+14 检查点

点地、「过来」、自主走动已从小家接入，原画起立、四拍步行和收步沿同一地线对齐。独立试玩发现急转前腿伸得过长和耳饰跳面，分别补了中间支撑姿态和固定耳位。模拟器在飞行模式下从 0.15 试装版覆盖，保留此前安装记录，家庭原签名的覆盖和两端设备验收仍待实测。[固定机位、穿戴与包摘要](evidence/fox-walk/README.md) · [原家庭下载入口](DELIVERY.md)

### 家庭功能 0.17.0+15

《奶油的雨天地图》沿用奶油画回家地图的愿望。Alice 陪它过石桥，每走过三块石板就在地图上盖一个爪印。十二块石板留下四个印，奶油据此带桃桃回家。进阶玩法从三个印反推九块石板，完成后可重看留在伙伴回忆里的地图。[奶油的角色设定](WORLD_AND_COMPANIONS.md)

亲密度按每只伙伴的首次触摸和呼唤显示初见、熟悉或默契。共同完成的故事留在伙伴回忆。进度与回忆随整个加密家庭档保存。更正后的同一笔成果可关联补记一次。备份生成、解密验证与恢复保护可显示进度并取消。[检查点与可安装包](evidence/family-functions/README.md) · [制作组分工](GAME_STUDIO.md) · [备份换机](BACKUP_MIGRATION.md)

加密迁移补测把账本、房间、衣饰、心愿、回忆与两章剧情放到同一个可往返家庭。49.84 MiB 合成存档的 Linux 调试基线已记录，安卓与 iPad 的 release 性能和系统文件互通继续列入设备验收。[离线补测](evidence/family-offline/README.md)

### 家庭更新 0.18.0+16

按家长的新增要求接入 Android 应用更新。家长主动查询 GitHub 版本、下载校验过的 APK，并在系统界面确认。公开仓库可匿名检查，当前私有下载仓库支持设备本地的只读令牌。更新数据与家庭备份分别保存。后续签名包和版本记录同批发布。[安装说明](DELIVERY.md#app-内更新) · [更新验证](evidence/android-updates/README.md)

### 备份性能 0.19.0+17

合并重复的成果流水查找。49.84 MiB 加密备份在云端两次复测中，导出最慢 18.486 秒，恢复最慢 13.968 秒，均核对了业务摘要。两端实体机仍需用同一版本核验安装、双向迁移和性能。[复测与签名包](evidence/backup-performance/README.md)

真机联调准备了 49.95 MiB 合成档，含 10,706 条流水和 21 件待确认小事，可在双端核对同一份账本、成长、衣饰及章节进度。设备往返用解密后的业务摘要比对。[合成档与验收步骤](evidence/device-acceptance/README.md)

### 伙伴解锁与独立成长 0.21.0+19

开局保留一位免费首宠，在小家的伙伴页确认用 30 分解锁另一位。伙伴按各自收到的已确认成果成长，旧档把原经验与最高已获阶段保留给现有伙伴。79 项 Flutter 回归和安卓离线覆盖通过。检查包含重复解锁、纠错归属、备份回迁和亲密回忆。[本轮实测](evidence/companion-unlock/README.md) · [旧档与换机](BACKUP_MIGRATION.md#021-伙伴成长档案)

两个隔离的安卓测试用户已通过系统文件往返恢复。原机归档后建立内部恢复点，接回第二端新增的成果与剧情进度。两位伙伴的独立经验和原有账本、搭配一并核对。[系统文件往返记录](evidence/companion-unlock/native-migration/README.md)

### 小事加载 0.20.0+18

小家和家长确认先读当前小事。翻看成长、已完成、更正或管理时加载历史列表，打开记录读原详情。用同一份万条流水夹具复测确认，云端界面 p95 从 866 毫秒降到两轮的 225 和 283 毫秒。真机冷启动和确认计时继续列入验收。[复测与签名包](evidence/task-performance/README.md)

0.20 云端补测已归档原机接收返程文件，两边回读校验，通过原机的内部恢复点保护和重开存档复核。关掉模拟器后，同一万条流水档两轮加密导出和恢复均在 20 秒内。[原机回迁与万条档计时](evidence/migration-return/README.md)

## Demo 的使用方式

第一个原生版本先在真实渲染尺寸并排对照网页，核对宠物轮廓、层级与状态。原生页面可重排按钮，让孩子的下一步操作清楚可见。用户已经确认的方向由 Codex 自测；普通迭代和修复直接继续。正式账户、数据与验收期望来自配置和业务文档。网页的浏览器存储、演示家长入口、自由预览和示例商品价格只用于演示。

## 设备与授权依赖

- **云电脑**。先跑准备检查和可独立测试。记录签名与设备的缺口，并继续不受影响的任务。
- **苹果端**。需要可运行匹配版本 Xcode 的 macOS。读取个人 Mac、使用 Apple 身份或连接 Alice 的 iPad 之前，按用户授权范围操作。真实型号、系统版本、安装与覆盖更新方式录入验收报告。
- **安卓端**。先在模拟器回归，再用真实手机验证系统文件选择器、飞行模式、签名 APK 安装与覆盖更新。长期保留发布签名身份，避免换签导致家庭无法原地升级。
- **交付给家长**。候选版本包含安装件或实际可用安装入口、使用与备份迁移说明、源码提交号、安装件摘要及逐项验收记录。遇到设备或账号限制，相关项目记为 BLOCKED；用户自行决定是否先验收已完成部分。
