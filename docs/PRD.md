# 产品需求

开工基线 v1.1 · 2026-11-18。本地离线是正式需求；其余默认边界见README。

## 目标

让现实努力得到家长确认、具体反馈、自主兑换与持久成长成果。不以使用时长、回访次数或游戏产出评价成功。

一个家庭、一名孩子；在一台当前设备上切换儿童与家长模式。完整数据可以迁移到另一台iOS或安卓设备。此范围中的跨设备指整套迁移，不指多设备独立写入后自动合并；若用户选择协作模式应先补充冲突设计。

## 角色

| 角色 | 权限 |
|---|---|
| 家长模式 | 自定义任务、确认/补录、扣分、纠错、配置家长PIN、备份、恢复和迁移 |
| 儿童模式 | 查看任务、申报完成、看反馈、兑换、换装、布置、看成长记录 |

家长通过本地PIN进入模式，无在线账号。可记录操作家长的显示名，但首版不提供多个独立家长账号体系。每次退出到后台立即结束家长会话，防止孩子接手时仍有管理权限。

## 首版内容量

银杏狐（奶油）、月牙耳兔（桃桃）、云翼猫（团团）首次使用即可任选。每只都有初始造型和五次外观变化，共18套阶段外观。三只共用一个免费家园 base_room。兑换目录另有18个条目，包括4个小装饰、4个配饰、4个单件家具/衣服、2个主题套装、2个功能区、2个店铺。准确ID与组成见catalog.json。

正式美术采用已演示的 C 版银杏树屋、草地和溪流，三只宠物分别以叶尾、月牙耳、云翼表现成长。当前伙伴和已获得的阶段随家庭保存。切换伙伴沿用当前已获阶段。目录中的花园 garden 和树屋 treehouse 分别开启可独立命名、单独布置的功能区；兑换前已能看到免费家园背景里的树屋与花草。商品和场景是成果容器，不提供营业、收菜、补货或维护。

## 典型流程

家长在当前设备创建任务，切回儿童模式。Alice查看并申报；家长输入PIN确认，立即在本地结算。Alice可以兑换或积累，已有物品和记录在重启后保留。

换设备时，家长导出完整迁移文件，系统冻结源设备的新增写入；目标设备从系统文件选择器导入、验证并建立新的本地家长凭据。没有远程连接时不会知道另一台设备的实时状态，不声称提供自动同步。

## 不纳入首版

云账号、云端后端、自动跨设备同步、多人在线协作、公众社交、学校接入、实物或现金兑换、广告、支付、AI聊天、自动任务推荐与审核、照片/语音证据上传。未来增加协作不得绕过单积分和并发正确性要求。

## 数据与体验

全部家庭内容保存在App私有存储，文件导出由家长主动操作。首页不展示假任务、假分数或假成绩；初始为空也能使用。无网络时不显示无法解决的登录墙。

App内自动恢复副本不等于外部备份。卸载或设备丢失前未导出的数据不能承诺恢复；应提供明确、轻量的备份状态入口，不能以频繁提醒制造负担。

浏览器 Demo 用于核对构图、伙伴和姿态，浏览器记录仅供演示。正式版从新家庭或有效备份开始。业务规则见RULES；实现与文件格式见TECH_SPEC/BACKUP_FORMAT；真实验收见ACCEPTANCE。
