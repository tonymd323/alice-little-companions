## 0.10 手绘互动家园

本轮手机体验反馈明确沿用 C 版银杏院落的水粉光色、角色轮廓和三宠六阶段。庭院保留原场景底画，暖廊是同一户小家可直接进入的室内机位，窗外延续银杏、溪水与桥。暖廊家具按窗座、梁柱和地面的固定画位呈现。旧家庭保留已购家具的空间归属，未曾摆出的家具也会在暖廊出现。三位伙伴的两件衣服随姿态绘制，头饰、眼镜、围巾随同一张角色网格运动。兑换目录中的四个独立空间仍依各自所有权开放。

三宠按原设定重绘透明轮廓。原生 Flutter 对角色绘制局部形变网格，脚掌、眼睛、耳尖、尾巴与云翼各有权重。待机轻呼吸、定时眨眼，点按有各自的回应，抚摸时头部跟手，点可行走地面可挪步。切入后台或覆盖页面停止时钟，减少动态效果时用文字回应。纸白、木褐、银杏金沿用庭院色彩，赤陶色用于主操作，青蓝和灰紫分别帮助辨认空间与兑换。庭院和暖廊切换、抚摸、外观预览均属于本地展示。

各阶段由有效成果日期累计触发。同一家庭的一份成长记录对应当前所选伙伴的外观。进入预览只改变显示状态。

## 家园、空间和触控

- **场景 C**。树冠用明亮的银杏黄，水面保留钴蓝，草地使用黄绿与树荫绿。木板、树皮、石岸有手绘水粉与水彩笔触。宠物沿用设定板细线与明快面色。全项目使用非像素美术。
- **构图**。左侧树屋、右侧木桥和溪水保留在同一机位。日常伙伴置于草地前景。Demo 宠物框中心横坐标为可见画面 47%，底边纵坐标 95%，按六阶段分别占可见画面高度的 24%、27%、30%、34%、36%、39%。原生首版以这组数值起步，调整耳尖或翼缘与桥栏相交的位置。
- **操作区**。任务确认、换装、家具预览与返回使用原生可交互控件。优先将任务信息和常用操作放在画幅边缘或画外，在手机上换行重排。家长界面使用同系列暖白底色、列表和表单。图片内不承载界面文案。
- **空间边界**。C 版庭院是免费家园的视觉入口，建议沿用 `base_room` 存储键。远景中的树屋是背景。目录中的花园、树屋、甜品店与花店在解锁后各有可摆放空间，由各自空间 ID 管理布局。
- **摆放**。场景、家具、接触阴影、宠物、衣饰、前景遮挡及控件按层绘制。家具落脚点和占地边界按完整背景的归一化坐标保存。屏幕裁切时对命中点做逆变换。溪水、桥栏不可落物，空间里的摆放区域、遮挡及配饰锚点需要结合实际素材校准。[场景布局](../design/scene_slots.json)
- **按钮与字体**。界面沿用暖白、鼠尾草绿主色。儿童正文 16–18 逻辑像素，主要按钮 18；家长正文 14–16。触控命中区至少 48 × 48，普通文本对比度至少 4.5:1，文字放大至 130% 后主要操作可达。[界面参数](../design/tokens.json)
- **动效与声音**。亲子确认成功可触发一次简短庆祝，最长 1.6 秒、可跳过。开启减少动态效果后保留最终外观与成果文案。声音默认关闭，退到后台停止待机动画。

| 状态 | 交付判定 |
