当前以第一阶段团团的普通走动校准表演。原画师先在庭院原光线下画出四足承重的站姿，锁定脸、毛边、足底和地线，再出起身、交替跨步、转向与收步。工程与试玩使用同一组姿态及脚掌标记。家具先在目标房间里画，衣饰先在目标姿态上画，各自的遮挡和投影随原稿交付。[原画交接与技术方案](TECH_SPEC.md#原画与运行素材) · [小家画面验收](ACCEPTANCE.md#小家画面与剧情验收)

## 0.10 手绘互动家园

本轮手机体验反馈明确沿用 C 版银杏院落的水粉光色、角色轮廓和三宠六阶段。庭院保留原场景底画，暖廊是同一户小家可直接进入的室内机位，窗外延续银杏、溪水与桥。暖廊家具按窗座、梁柱和地面的固定画位呈现。旧家庭保留已购家具的空间归属，未曾摆出的家具也会在暖廊出现。三位伙伴的两件衣服随姿态绘制，头饰、眼镜、围巾随同一张角色网格运动。兑换目录中的四个独立空间仍依各自所有权开放。

三宠按原设定重绘透明轮廓。原生 Flutter 对角色绘制局部形变网格，脚掌、眼睛、耳尖、尾巴与云翼各有权重。待机轻呼吸、定时眨眼，点按有各自的回应，抚摸时头部跟手，点可行走地面可挪步。切入后台或覆盖页面停止时钟，减少动态效果时用文字回应。纸白、木褐、银杏金沿用庭院色彩，赤陶色用于主操作，青蓝和灰紫分别帮助辨认空间与兑换。庭院和暖廊切换、抚摸、外观预览均属于本地展示。

## 家园、空间和触控

- **场景 C**。树冠用明亮的银杏黄，水面保留钴蓝，草地使用黄绿与树荫绿。木板、树皮、石岸有手绘水粉与水彩笔触。宠物沿用设定板细线与明快面色。全项目使用非像素美术。
- **构图**。左侧树屋、右侧木桥和溪水保留在同一机位。日常伙伴置于草地前景。Demo 宠物框中心横坐标为可见画面 47%，底边纵坐标 95%，按六阶段分别占可见画面高度的 24%、27%、30%、34%、36%、39%。原生首版以这组数值起步，调整耳尖或翼缘与桥栏相交的位置。
- **操作区**。任务确认、换装、家具预览与返回使用原生可交互控件。优先将任务信息和常用操作放在画幅边缘或画外，在手机上换行重排。家长界面使用同系列暖白底色、列表和表单。图片内不承载界面文案。
- **空间边界**。C 版庭院是免费家园 `base_room` 的视觉入口，远景中的树屋属于背景。花园、树屋、甜品店与花店在解锁后打开各自有名字和固定陈设的空间。
- **陈设**。美术在完整背景上指定家具的固定画位、落脚点、占地、光影和前景遮挡。玩家看实景预览，兑换后直接入景。按空间 ID 读取旧家具归属，屏幕裁切时统一转换绘制与命中坐标。[场景布局](../design/scene_slots.json) · [固定画位](../apps/mobile/lib/illustration/room_painting.dart)
- **按钮与字体**。暖纸色作底、木褐色作正文、赤陶色用于主操作；银杏金与草木绿保留在场景及有含义的反馈中。儿童正文 16–18 逻辑像素，主要按钮 18，家长正文 14–16。触控区至少 48 × 48，普通文本对比度至少 4.5:1，文字放大至 130% 后主要操作可达。[界面参数](../design/tokens.json) · [家庭版主题](../apps/mobile/lib/features/garden.dart)
- **动效与声音**。亲子确认成功可触发一次简短庆祝，最长 1.6 秒、可跳过。开启减少动态效果后保留最终外观与成果文案。声音默认关闭，退到后台停止待机动画。

## 0.13 日用版已接入的动作

庭院银杏与水面随风变化，暖廊的窗帘和地面光斑跟随微风。伙伴能环顾、伸展、走向落点、蹭手和施展技能。银杏狐卷起金叶，月牙耳兔两次腾跃，云翼猫踏着云气跃起。离地使用独立的手绘动作姿态，杏色外套与围裙分别适配全部动作。进化中能辨认旧形、新形和当前衣饰。减少动态效果时直接呈现结果。

四种配饰随角色实际姿态装配。帽子、蝴蝶结、围巾为三宠各画静态和腾跃视角，衣料配合角色身形。眼镜按两眼的位置分别画近镜片、远镜片、鼻梁和镜腿。帽檐以头顶定位，蝴蝶结系在近耳根，围巾前沿由下颌的原画压住。主线通关后，暖廊窗上的金叶与地面倒影绘在家具与角色之后。


## 风过暖廊 · 角色表演与彩窗

第三阶段桃桃的围巾画进角色姿态里。分别处理耳根转向、颈毛压布、前爪钩住围巾与松爪回弹。推篮时校准爪与篮沿，布角随后落定。家庭衣橱有原装、外套和围裙对应的坐姿与腾跃成画。奶油的桥上循环包含四种脚步，停下与进门另有姿态。

暖廊的三个窗框各有四块可独立嵌合的彩玻璃。玻璃受木框裁切，桥光和木地板的投影按窗逐扇绘制。光落到对应桥段后，奶油才沿连续的部分向前。结局另按日常暖廊原机位重绘遮挡和投影，家具与伙伴显示在它们之前。[场景分层原稿](../design/production/wind/room/README.md) · [游戏实际画面](evidence/wind/README.md)
