# 从银杏家园 Demo 到正式 App

**开发目标**　Alice 的现实成果由家长看见并确认。每个成果可以留下评语、积分和成长记录。积分只有一种，仅用于永久的 App 内物品和空间。

可操作参考见[银杏树屋 · 月牙耳兔第四阶段](https://alice-little-companions-demo.tonymei323.chatgpt.site/?pet=rabbit&stage=4)。参考源码提交为 `285b9cac8771b7db0483f6ff764ac33aa775716a`。参数 `pet` 和 `stage` 仅用于网页预览。此前的浏览器数据只属于 Demo；正式版首次使用创建本地家庭，或导入正式版支持的加密备份。

## 三种任务与两种成果

| 家长选择的类型 | 选择依据 | 达标后发分 |
|---|---|---:|
| 轻量行动 | 完成标准清楚、步骤少 | 2 |
| 持续投入 | 需要一段专注投入，或包含多个相关步骤 | 3 |
| 突破挑战 | 对 Alice 当前能力有新的挑战，能事先说明如何确认 | 5 |

- **发布**　家长命名、填写完成标准、选择投入类型。说明可选。单次、重复、分阶段分别控制执行方式；同一种投入类型适用于三种方式。首次使用时任务列表为空。
- **发分**　儿童申报进入待确认。家长确认后，用发布时的分值快照一次结算。项目各阶段独立计分，2、3、5分的三个阶段合计10分。退回继续、到期或未完成都保留原有余额。有来源和日期的家长补录按相同规则结算。
- **成长**　家长每确认一件有效成果，家庭获得 1 点共享经验，同日多件分别计算。六阶段的累计经验门槛为 0、3、10、20、35、55。发生日期用于手记。纠错后重算经验，保留已解锁外观。0.12 及更早存档按有效成果回算经验，并保留当时获得的阶段。
- **扣分**　家长事先约定行为、条件和1/2/3分档位，事后记录事实。实扣取预设金额、可用余额、当日剩余额度三者的最小值。按操作当日家庭日期累计最多3分，撤销只退实际扣额一次，当日已用额度保持。
- **兑换**　6分小装饰、12分配饰、25分单件、50分套装、90分功能区、120分店铺。30分/周是定价参照。每个独有商品只购买一次，每笔退款关联原购买记录。家具在所属空间的固定画位呈现，旧档保留已有归属。误触撤销、误奖纠错和预算提示执行现行业务规则。
- **反馈**　先呈现家长写下的具体反馈，再呈现积分和适用的外观变化。无反馈时显示真实任务名、日期与确认结果。点宠物、在线、离线和布置的积分变动均为0。

## 已处理的设计差异

| 对照项 | 正式版开发口径 | 验证动作 |
|---|---|---|
| 早期材料为单只奶油狐，当前 Demo 有三位伙伴 | 银杏狐奶油、月牙耳兔桃桃、云翼猫团团均可免费选择，每种六阶段，共18种基础外观。沿用 Demo 的家庭共享进度做法，一个时刻展示一位当前伙伴 | 在同一成长阶段换伙伴，核对余额、共享经验、已解锁阶段与所有权。在三个角色上分别检查五次升级的轮廓变化 |
| 原免费房间换为 C 版户外家园 | 默认家园是银杏树屋外的草地、木桥与溪流，首次启动即可见。另购花园或树屋功能区后可进入、命名，各有固定陈设 | 切换伙伴时保持机位，检查耳尖、云翼、银杏尾的轮廓。第四阶段云翼猫日常收翼，升级时展翼。检查初次启动免费背景与付费空间的区别 |
| Demo 可自由试览所有阶段 | 可查看未解锁造型再返回当前伙伴。预览穿戴和房间效果使用临时状态，确认兑换才扣分，穿上已有衣饰免费 | 记录余额、账本、共享经验、已解锁阶段、当前伙伴及搭配，浏览后退出并逐项比较。真实升级在确认事务完成后展示一次 |
| Demo 只演示单次任务与简易正向结算 | 正式版支持快照、重复/阶段、退回、补录、扣分、退款和纠错。本机 SQLite 事务保证一次性 | 对同一任务重复确认、同一商品重复购买，核对账本与所有权；按原有 AC-04 至 AC-20 执行异常用例 |
| Demo 的五个试用商品 | 正式版目录18项。套装组件与功能区/店铺基础布置随原购买发放，组件关系和退款跟随正式目录 | 预览、购买、查看固定画位、重开、退款。核对原价返还一次，退款空间中的另购家具回物品栏 |
| Demo 靠浏览器记录，演示入口可直接切家长模式；历史草案曾设联网入账 | 正式安装包首次运行可全程飞行模式。真实家长凭据保护管理操作；家庭在一台当前设备写入。备份可复制，迁移成功后源端只读，目标继续使用 | 安装包重启、杀进程、系统文件选择器，以及 iPad 与安卓双向迁移均取真机证据 |
| Demo 的切换和图集可用，18款角色与其他素材完成度不同 | 18阶段图是外观参考；按正式素材清单检查精度、透明边缘、锚点、图层和离线打包。尚未验收的商品、功能区与店内画面须完成后验收 | 以角色与阶段为行、装扮槽位为列检查裁切和遮挡，记录缺图与待补资产；正式候选包中运行检查 |

产品与交互按此表解释 Demo。完整规则语义以 RULES 为准，数值以 rules.json 为准，商品与组件以 catalog.json 为准。家庭小事的内容由家长填写。内置二年级数学在主线中推进剧情，重玩保留原有家庭积分与共享经验。
