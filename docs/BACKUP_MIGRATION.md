# 家庭备份与换机

所有步骤可在飞行模式下完成。备份文件为 `.alicebackup`。它保存整个小家，包括自定义小事与成果、积分流水、兑换、空间布置、当前伙伴、三只伙伴的搭配、共同成长和心愿。

从家庭版 0.11.0 起，《暖廊的彩窗》的页码和完成时选定的两格花纹会一起备份。恢复这类新备份时，目标设备需要家庭版 0.11.0 或更高的兼容版本。0.10.0 及更早的受支持家庭存档可直接升级，第一次打开彩窗会从第一扇窗开始。独立试玩版的书签保存在试玩 App 自己的目录中。

## 备份到 App 外

1. 在右上角进入 **家长入口**，用本机 PIN 解锁，打开 **备份与迁移 → 导出备份**。
2. 设置至少 10 个字符的独立备份口令，输入两次。空格、大小写和 Unicode 写法会原样参与校验。请单独保管口令。
3. 点 **生成并保存文件**，在系统文件选择器中选 App 外的位置。安卓可选 **Download**，iPad 可选「文件」中的本机文件夹或外置存储。使用云盘时以系统文件提供者的行为为准。
4. 数据页如果显示「等待回读验证」，用 **回读验证导出文件** 重新选择刚保存的文件，输入备份口令。已验证时间会出现在数据页。取消或保存中断可重新尝试。

设备内会为升级、替换和纠错保留最近 5 个加密恢复点。卸载、丢失设备或清除应用数据时，请使用先前保存到 App 外并回读过的文件。

## 从旧设备迁移

1. 在旧设备打开 **家长入口 → 备份与迁移 → 迁移到新设备**。设置备份口令，保存并回读文件。旧设备在生成迁移文件后暂停写入。如果保存回执待核实，会保持只读。
2. 通过电脑或两台设备都能读取的外置存储传递加密文件。请在目标设备上保留原文件的副本。
3. 在新设备首次启动时选 **从备份恢复**。已有小家的设备在 **家长入口 → 备份与迁移 → 从外部备份恢复** 选择文件。系统文件面板返回后，App 可能要求重新验证当前设备的家长 PIN。
4. 输原备份口令，核对待恢复的孩子称呼、余额、成果、流水、物品、空间及伙伴阶段。如果目标已使用，App 会先建立内部恢复点，再请家长确认整体替换。
5. 为新设备输入并确认新的六位家长 PIN，保存新恢复密钥，激活存档。核对成长记录、所选伙伴、换装、布置和心愿。之后在新设备处理新的成果。
6. 在旧设备回读迁移文件，并确认新设备恢复成功后可点 **归档旧设备**。如果已确认新设备从未继续使用此存档，可以在旧设备 **取消迁移并恢复写入**。

同一份备份再次导入会显示「已经恢复」，或者在目标已有新变化时重新要求确认完整替换。同一家庭始终选一台设备继续记账。两份各自修改过的文件由家长选择其中一份整体恢复。

## 家长凭据与恢复

- **忘记 PIN**。在家长解锁页选择 **用恢复密钥重设**，填写原恢复密钥并设置新 PIN。请保存新恢复密钥。
- **忘记备份口令**。仍能进入原小家时，可重新导出并设置新口令。旧文件需要当时的原始口令。
- **口令错误或文件有损坏**。重新选择文件或从源设备重新导出。系统在派生密钥、解密、结构、积分与素材校验通过后才显示恢复比较页。
- **设备存档读不出**。如 App 能识别当前设备和已存凭据，可在恢复页用当前家长 PIN 选择一个内部恢复点或外部备份。旧存档文件保留，激活新存档时设新凭据。

## 0.13 日用版的覆盖与换机

在旧设备上先从家长入口导出一份加密备份，保管好文件和口令。安卓打开同一家庭应用的 0.13 APK，选择“更新”。第一次打开会按每件有效成果 1 经验回算三只伙伴的共享成长，已有更高阶段会保留。

目标设备使用 0.13 或更新的兼容家庭版，导入时核对余额、有效成果数、恢复后的阶段、物品与空间。0.13 使用 SQLite 结构 5，能读取结构 1–4 的旧包；旧应用需先升级才可打开新包。积分流水、已购家具、伙伴穿戴、数学书签和已有成长授予记录逐行保留。手记与互动动画随应用安装。完成换机后在目标设备冷启动复核，再按上文处理源机。

彩窗亮起后，主线结局随存档进入目标设备。已通关再重玩仍可在家中看到三扇窗花。旧版数学书签在结局或进阶页时，更新后会接上同一个结局。
