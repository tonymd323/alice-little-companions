# 银杏家园 · 视觉素材派单包

Alice 的小家在老银杏树下。庭院里有树屋、草地、石桥和溪水，走进暖廊还能从窗外认出同一座桥。把新画的东西放回这里，孩子应该能认出它、看懂它怎样被使用。

[从项目仓库下载完整 ZIP](https://github.com/tonymd323/alice-little-companions/archive/refs/heads/codex/visual-agent-kit.zip) · [直接挑选可复制的工单](https://github.com/tonymd323/alice-little-companions/tree/codex/visual-agent-kit/jobs)

## 拿到包就能开工

1. 在 `jobs/` 选一张工单，把整段文字交给绘制 Agent，附上工单列出的 `refs/` 文件。能读 ZIP 的 Agent 可直接拿整包和工单编号。只接收图片的工具先附本单的主参考，再附身份板或画风图，把坐标、动作节拍从工单带入文字指令。
2. 把产物放回 `returns/工单号/r01/`。同一资产族由一个人维护母稿。依赖另一张工单时，把已选母稿的实际文件和版本一起交下去。同一只新宠的六阶段和服装都从这一稿展开。
3. 独立评审拿同一工单、原图与实际成品，按[验收表](ACCEPTANCE.md)复看。把具体帧号、像素位置或冲突图层交回原作者。作者返修时升为 `r02`，复检同一处，再看相邻姿态。家长保留最终体验验收。

| 第一批可直接并行 | 给谁 | 看什么再扩量 |
|---|---|---|
| `SC-01` 雨后石桥庭院 | 场景原画 | 空景里能认出原树屋和桥，湿木与流水有不同的受光 |
| `AC-01` 奶油的栗叶耳结 | 配饰原画 | 正、侧、背都系在自身右耳，左向远耳结可变小、受遮挡 |
| `SP-01` 溪纹水獭 | 角色设定 | 缩小后仍可由吻部、宽尾和身段辨认，再发它的 `EV-02` 六阶段单 |
| `MO-01` 幼年团团走近两小步 | 角色动画 | 手机大小、静音原速下能读出先看、压爪、移重和停稳，再扩转向与衣饰 |

首批共 21 张工单。原三宠各有一张六阶段校准单，另有两种新伙伴的设定与进化提案。雨后场景、商品和新物种均为候选。原版三位初始伙伴为奶油、桃桃、团团，共享成长经验。数学道具提供可看清、可分组的数量关系。

## 从一个主题扩成一批素材

| 可选主题 | 同一批可以画什么 | 合成时怎么检验 |
|---|---|---|
| 雨后过石桥 | 湿石面的空庭院、四组石板的地图、奶油装地图的背心、桥边捧叶的小水獭 | 新地图能放入左胁口袋，取出摊平后，孩子能按每组三块数清十二块石板 |
| 暖廊听雨 | 窗座、放卷图的矮凳、桃桃的月芽领巾、栗蓬刺猬的展台 | 缩到手机大小仍看得见窗格、角色和陈设的前后关系 |
| 花店分束 | 空工作台、六孔木盘、可抽取的花枝、晾花架、店围裙 | 一位 Agent 画空台，另一位按同一台沿和透视画道具。插满后抽走一枝，应能数出剩余五枝 |

扩量时给同主题各单写一个不同的用途、轮廓或操作结果。先把一件实物、一件穿戴和一位伙伴放回同一张底图复核，选中的光向、尺度和上游版本沿用到整批。已有商品的配色变体可在一张工单内列成多个色样。

## 继续派单

- [提示词](PROMPTS.md)含通用画风、八类绘制指令，以及制单、独立评审和定向返修三种指令。手工派单时依次复制“通用绘制”“对应类别”，再补上[工单表](jobs.csv)的一行。ZIP 里的 `jobs/*.txt` 已经拼好。
- [参考目录](references.csv)注明每个文件在原工程中的来源及用途。`refs/` 中有色彩方向稿、干净空景、三宠设定板、实际透明原画、穿戴与接点示例。画风图中自带的伙伴只供参照，空场景以对应的干净底图为准。
- 单行工单的字段为 `id`、`kind`、`asset_id`、`title`、`depends_on`、`refs`、`scope`、`canvas`、`brief`、`outputs`、`check`。在 `jobs.csv` 复制最相似的一行，换上唯一编号与文件前缀。引用及上游编号用 `|` 分隔。已收到的上游回件随单附上。
- 在本目录执行 `python3 build_pack.py /目标目录/alice-visual-agent-kit.zip` 可重新生成每单提示词和整包。在工程内首次打包使用 Pillow 把 WebP 原画无损转存 PNG。解压后的派单包可直接用现有参考文件在离线环境重编工单。参考来源与实际打包文件的 SHA-256 记在 `reference-index.json`。

原画基线取自家庭版 0.16 所在开发分支。该版的旧步态片记录了体态突然拉长、转面偏硬等家长反馈。动作工单用它定位返工点。[美术规范](https://github.com/tonymd323/alice-little-companions/blob/b6c4242/docs/DESIGN_SPEC.md) · [当前表演要求](https://github.com/tonymd323/alice-little-companions/blob/b6c4242/docs/ACCEPTANCE.md) · [团团短程预演记录](https://github.com/tonymd323/alice-little-companions/blob/codex/tuantuan-motion-preview/docs/evidence/tuantuan-approach/README.md)
