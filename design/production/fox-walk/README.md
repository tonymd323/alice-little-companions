# 第一阶段奶油 · 家园步态开工

在同一地线上复看了奶油的家园坐姿、腾跃和暖廊的四张跑步原画。暖廊已经画出前爪着地、后爪蹬伸和收步，参考原稿可以看到胸毛、前爪和银杏尾的分层。它们用于取轮廓、毛色与受力参考。奶油的日常步态需再画清四足站稳和一只爪离地时的支撑关系。[八姿原画对照](reference.jpg) · [暖廊分层原稿](../wind/actors/fox-poses.ora)

首个镜头放在团团测试的同一处庭院。奶油先竖起一边耳朵，前身压低半步，站起来沿地面挪动，再移重心坐回。尾尖晚半拍跟上，亮色尾尖和白胸毛仍沿用 C 版。近、远前后的爪垫各自标注，点地和「过来」先走同一个目标，再试斜向。暖廊的跑步继续用于原章节的回家演出。[奶油的角色设定](../../../docs/WORLD_AND_COMPANIONS.md#奶油--银杏狐)

家园慢走姿态、衣饰转面和独立试玩待制作。本次留存的画面是已有源画的摆位对照。
