# 第一阶段团团的庭院步态

团团的第一阶段沿用原来的蓝灰毛色、圆蓝眼睛、珊瑚色耳朵和卷尾。右向头部从 C 版原画取出，并留出压在围巾与领口前的颈毛。补画了横向站姿的肩背、尾巴、四条腿和白爪。正面有完整五官和胸毛，背向保留耳型、后脑花纹和尾巴。杏色外套保有银杏口袋、领口和袖口。紫围裙保有褶皱、蝴蝶结、花口袋和浅色花边。离线 WebP 随原游戏加载。

## 画面与时点

- 坐着的团团先将头往前探。近前爪承担重量时，后腿收到身下，髋部抬升。收步等脚爪落稳后，重心回到后髋，胸口和尾巴再放松。
- 慢走顺序为近后、近前、远后、远前。每拍留两张关键姿，分别画明掌缘落地与另一条腿从身体下方抬过。试片上的实心绿点指承重爪，橙色空圈指经过中的悬空爪。运行时对各条腿做连续补间。
- 转身从右向姿态过到正面或背面。衣服有对应的纵向视角。背面的杏色外套保留领口和缝线，紫围裙展示背结。头饰和颈部配饰由客户端随这三种头部画稿的锚点合成。

画布尺寸为 512 × 464，地面基准点为 (256, 440)。原坐姿画幅高 440。路径里的步长基准依画布尺计算，运行时依据身体实际移动距离推进步相。试片使用 132 画布像素的循环伸展量和 75% 的承重段，供画稿对比。原装预演 4.1 秒，每秒 30 帧，固定画框展示起身、两轮慢走、转向和坐回。庭院中真实掌缘的测量使用应用取帧。

| 图层 | 画布与安装点 |
|---|---|
| 头、尾、躯干和外衣边 | 与整张画布同尺寸。头、尾基点及三套视角的帽、耳、眼、颈位置见姿态表。侧面袖口单独压住前腿根，正背面的衣服各有完整图层。 |
| 八个腿段 | 每片 128 × 160，向下画。关节中心在 (64, 32) 与 (64, 128)。连接处留有可重叠的毛边。 |
| 四个爪 | 每片 128 × 100，朝右画，腕部结合点 (64, 55)，掌缘中点 (64, 84)。远足颜色较暗，近足保持原画奶油白。 |

## 编辑与导出

Krita 或 GIMP 可打开分层原稿，逐组看站姿、换装、两个纵向姿态、撑起、收步和慢走八姿。SVG 笔触与色层可在 Inkscape 编辑，`face-source.png` 是原 C 版坐姿 WebP 的无损解码副本。颜色、灯影和纸面纹理烘焙到运行图层。用 Inkscape 与 Pillow 重新导出。原速预演另需 FFmpeg。

```sh
python3 design/production/cat-walk/export_art.py
python3 design/production/cat-walk/rehearse_art.py
```
