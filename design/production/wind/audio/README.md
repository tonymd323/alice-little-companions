## 原声与导出

七项拟音均为本项目原创程序合成。源件保留噪声频带、布料和藤条摩擦的包络、木板与玻璃的共振以及每一步爪音的位置。未采样第三方曲目或人声。全部导出为 32 kHz、16 位 PCM 双声道 WAV，单个文件的采样峰值在 −10.2 至 −5.4 dBFS 之间。试听带的采样峰值为 −5.4 dBFS。

在仓库根目录运行以下命令可重建游戏里的七个声音和本目录的试听带。本次渲染使用 NumPy 2.3.5 和 SciPy 1.17.0。种子和参数已写入源件。

```sh
python3 design/production/wind/audio/render_foley.py
```

## 接入镜头

引用 `lib/illustration/wind_sound.dart`。进入镜头时读取 `WindSound.isMuted()` 并调用 `WindSound.prepare()`。在动作接触点调用 `WindSound.play(WindCue.seatLeaf)` 等事件。重复点击同一种材料时从头播放那一个声音，不同材料可以叠响。出页调用 `WindSound.stop()`。恢复前台时由下一次玩家动作触发声音。所有方法均异步返回，画面与存档可独立进行。

`WindSound.setMuted(true)` 会停止当前声音并记住本机选择。Android 使用游戏媒体音量并与其他音频混合；iOS 采用 `.ambient` 混音和静音键。该偏好写入 Android SharedPreferences 或 iOS UserDefaults。每个 WAV 随应用打包，可以在飞行模式和系统静音下进行同一段操作。

苹果端实际构建、硬件静音键、与其他应用混音，以及家庭手机扬声器的主观听感，分别在对应设备上核验。
