# 风过暖廊 · 角色演出原稿

桃桃是第三阶段的月牙耳兔，奶油沿用初次见面的银杏狐。原画对照取自 C 版的兔子与狐狸、各自已有的腾跃稿以及衣橱中的鼠尾草围巾。新姿态用 ImageGen 按同一套参考绘制，窗光由画面左上照入。桃桃的每个姿态都同时画了颈毛、布褶、金叶绣纹与接触阴影。[桃桃原画](../../../../apps/mobile/assets/art/rabbit-3.webp) · [奶油原画](../../../../apps/mobile/assets/art/fox-1.webp) · [衣橱参考](../../../../docs/evidence/daily/phone-accessories.jpg) · [同机位穿戴与推篮近景](wardrobe-light-study.jpg)

## 怎样看表演

桃桃先停下来听风，一边耳朵比另一边更早抬起。布边飞起时，它低头把爪压上去。探爪后后脚蹬住地面、双肘伸开，随着竹篮右移。松爪时身体往回坐。奶油看到亮处才试探着迈脚，回家时先刹步再坐下。动作预演使用本轮暖廊原画、固定机位和 24 帧/秒无声播放，共 176 帧。动画时点在安装包中随玩家操作衔接。[7.33 秒原画预演](acting-rehearsal.mp4)

| 动作 | 原稿中的姿态名称 |
|---|---|
| 桃桃转耳、护住围巾 | `idle → notice → listen → catch → guard` |
| 桃桃探爪、推矮篮、放开 | `reach → lower → push_low → stretch_low → recoil` |
| 桃桃向奶油招手 | `wavelift → wave → wavelift` |
| 较高的抵持动作备稿 | `push`、`stretch` |
| 奶油等候与相聚 | `wait → look → run1 → run2 → run3 → run4 → brake → arrive`。四张奔跑画稿可循环，分别能辨出前脚落地、收腿承重、后脚蹬伸和腾空收腹。 |

## 源件与编辑

三份 OpenRaster 工程包含无损 PNG。使用 Krita 或 GIMP 打开，一组对应一个原分辨率姿态，切换组的眼睛图标即可查看。桃桃的身体与耳、围巾与刺绣、布褶暗线、前景颈毛与近爪可以分别修笔。奶油分出前爪、胸前毛、尾巴及躯干。所有可见像素来自各姿态的完整成画。若需要画到当前姿态中被布料挡住的皮毛，可直接在该姿态的身体层补画。[桃桃 14 幅](rabbit-poses.ora) · [奶油 8 幅](fox-poses.ora) · [空篮、前沿与银杏叶](props.ora)

两幅推矮篮的动作使用与篮缘同高的青色排练道具建立受力关系，导出时按色相与透明度去除道具，再保留铅笔轮廓的抗锯齿边。近爪接触位置从画布的 `(.734, .714)` 移到 `(.927, .721)`，远爪从 `(.780, .687)` 移到 `(.973, .689)`。所有角色采用 512 × 448 画布，统一地面参照为 `(.47, .90)`。近爪、远爪、鼻、双耳尖、近眼、布结或尾尖均用各自画布的归一化坐标记录。物件源稿另列实际尺寸、篮缘接触点和五片叶的落点。[原稿配准数据](poses.json) · [运行时坐标](../../../../apps/mobile/assets/wind/actors/poses.json)

导出时先合成每个组内的可见画层，再按各自的裁切与落脚位置注册为固定画布。空篮本身没有叶片。舞台先绘篮底与内壁，再放可数的金叶，最上方盖同画布的篮子前壁。程序可以按玩家操作逐一取出叶片。

在项目根目录使用带 WebP 编码支持的 Pillow 13.0.0 运行以下核验。它重新合成三份工程并逐字节比对 25 张运行图，同时核对动作与道具坐标。编辑原画后，去掉 `--check` 即可重新导出到应用资源目录。若要试导到独立目录，使用 `--out /path/to/frames`。

```sh
python3 design/production/wind/actors/export_poses.py --check
```
