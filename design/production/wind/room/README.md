# 风过暖廊的两处机位

样片在暖廊靠近窗边的三扇实物彩窗前发生。每一格有自己的银杏叶脉、玻璃切线和焊边。每扇窗补满之后，石桥上对应的一段石面受光，室内木板也接到同一扇窗的透光。回到日常暖廊时，从房间原来的机位可以看见长椅后的彩窗、地板上的投影和远处的桥。

- [四种补窗进度](window-states.jpg)对照入场、先修中窗、先修右窗和全部修好的状态。
- [日常暖廊对照](home-comparison.jpg)展示原场景、永久修好后，以及装回应用内的靠垫、地毯与扶手椅。两张对照均使用运行素材合成。

## 可编辑绘画

[样片原稿](wind-room.ora)与[日常暖廊原稿](home-restoration.ora)可以用 Krita 或 GIMP 打开。原稿的命名图层使用屋内物体作为分层依据。样片含底画、十二块独立玻璃、三段桥光、三块木板透光和位于狐狸前方的桥栏。日常暖廊含原背景、窗、地板透光和远桥光。两个文档底部各保存了一张隐藏的完整修后绘画参考，方便继续修改颜色与材质。

原图以仓库的银杏家园 C 版、暖廊和庭院为美术参考，用 ImageGen 绘制。先锁定机位和硬件轮廓，再以原图为参考绘出修后玻璃与光。裁切边界跟随窗框、石面、布帘与木板。绘画尺寸和色彩沿用了暖廊原图的日间光线。所有游戏内颜色与投影随安装包提供。

## 在场景中叠放

[运行坐标表](../../../../apps/mobile/assets/wind/room/room.json)中的每个裁切框都按左、上、右、下给出，其零点位于画布左上角。样片镜头为 1086 × 1448，显示时等比缩放整个镜头。窗序从左向右，窗内按左上、右上、左下、右下编号。开场的十二格中有七格已经填好，分别属于左窗四格和中窗前三格。每块玻璃按其原始裁切框显示。每扇窗独立控制对应的桥光及地板光。

桥上行走的狐狸画在底画和光之上，前排桥栏绘在它前面。走入室内后，狐狸、桃桃及篮子处于近景地板上。坐标表中的桥点对应脚底，从左岸经桥顶走向右岸。

日常暖廊以 1536 × 1024 的 [veranda.webp](../../../../apps/mobile/assets/art/veranda.webp) 为底。将 home-restored.webp 放在完全相同的显示矩形中，然后按原来的次序叠放已购家具、伙伴和室内前景。家庭场景中的拖动视角和缩放应对这两张图使用同一个变换。

## 从原稿导出

绘图时可修改各层像素和偏移，保留每个图层名中第一个空格之前的英文标识。Linux 开发机使用 Python 3 和 Pillow。在仓库根目录执行以下命令即可从两份原稿得到 Flutter 的 18 张 WebP 及坐标表。

```bash
python3 design/production/wind/room/export_layers.py
```

此次实测使用 Pillow 13.0.0 和 libwebp 1.6.0。将结果导出到另一个目录，与打包素材逐文件比较一致。两份 OpenRaster 压缩包的完整性和 12 格坐标已核对，每个独立光区都有全透明与完全着色像素。日常修复层有 63.16% 的画面完全透明，保留原场景像素。
