# 团团两步走近

在庭院里的 2.90 秒无声原速片中，团团先瞄一眼，尾尖随后摆动。约 0.53 至 0.80 秒，前掌承重，肩和圆臀撑起来。两次迈步都由远前掌先接住重量，近前掌抬起约 0.08 秒后，近后掌再跟上。约 2.13 秒站稳，2.45 秒坐回，2.62 秒眨眼。[庭院原速片](courtyard.mp4) · [透明角色](transparent.webm) · [同机位姿态](pose-study.jpg)

首尾直接用 C 版一阶段团团原图。中间由原画全身连续形变，头和耳保留同一套纹理，臀、肩、前后掌与尾各有位置曲线。可见掌部的轮廓控制点随掌整体移动。固定方向为向右侧三分之二，只演示这次靠近。[C 版坐姿](../../../apps/mobile/assets/art/cat-1.webp) · [可编辑时序和支点](poses.json)

透明画布 720 × 464，30 帧每秒，共 87 帧。脚线 y = 440，根从 (230, 440) 到 (362, 440)。首尾与把 378 × 440 的原画放在 (41, 0) 和 (173, 0) 的结果逐像素相同。固定庭院样片采用 960 × 640 的既有底图，角色高度按画面高度的 0.343 校准，脚线为画面 y = 600，向右移动约 66 个视频像素，相当于 33 个逻辑像素。

清单中的承重点是人工设定的。分别对透明序列里三只可辨认的爪，在每次固定承重段内匹配掌底周边 25 × 17 像素，搜索范围为横纵各 5 像素，九段匹配偏移最多 1 个原画像素。运行画面的跟踪由同机位取帧复核。

使用 Python、NumPy、SciPy、Pillow 和 FFmpeg 重录。加 `--png` 可另存 `cat-000.png` 到 `cat-086.png`。

```sh
OPENBLAS_NUM_THREADS=1 python3 design/production/cat-approach/render.py --png /tmp/tuantuan-approach
```
